## Что нужно сделать с фотографиями при сборке

Оригиналы весят до 3 МБ и в таком виде на сайт не идут. По ТЗ §10 и §23:

- отдавать AVIF и WebP с responsive sizes, оригиналы оставить в `source/`;
- сохранять исходное соотношение сторон, кадрировать только согласованно;
- alt писать по видимому содержанию снимка, не по имени файла;
- не перекрывать лица текстом и плотными затемнениями (ТЗ §4);
- повторы отсеивать по SHA256.

## Alt-тексты

Каждое из 415 уникальных изображений, попавших на страницы, просмотрено;
alt написан по видимому содержанию снимка, без домысливания повода,
участников и дат (ТЗ §23). У карточек, где текст свёрстан картинкой
(афиши мероприятий, публикации «Московского образования», карточки
выпускников), alt передаёт написанное на них.

Тексты лежат в `src/content/image-alt.json` и подставляются слоем
контента: `pages.generated.json` перегенерируется из `source/` и руками
не правится.

Один файл выведен из показа: `IMG_7203_e3cb8a9898.webp` (1280×1280,
анонс похода «Большая Валдайская тропа») полностью чёрный — все пиксели
`#000000`. Это единственный такой файл из 415. Вопрос D-14 в
[QUESTIONS.md](../QUESTIONS.md).
