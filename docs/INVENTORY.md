# Инвентаризация и таблица соответствия

Этап 1 редизайна. Документ ведётся по разделам 3, 7 и 16 технического задания.

## Правило

Контент переносится с действующего сайта **без смысловых изменений**. Ничего не
придумывается, не сокращается и не переписывается. Спорные элементы отмечаются
статусом `review` и выносятся в [QUESTIONS.md](../QUESTIONS.md), но не удаляются
и не заменяются самостоятельно.

## Статус: не начата

Инвентаризация не выполнена. Причина — нет доступа к содержимому
`https://schooldmitrovsky.ru` из рабочего окружения: домен закрыт сетевой
политикой (egress-прокси отвечает `403` на `CONNECT`).

Что нужно для старта — любой из вариантов:

1. Разрешить домен `schooldmitrovsky.ru` в сетевых настройках окружения.
2. Передать выгрузку сайта: HTML-страницы, изображения, документы, экспорт из
   текущей CMS или конструктора.
3. Передать доступ к текущей админке.

Пока источник недоступен, слой контента (`src/content/`) остаётся пустым, а
компоненты собраны так, чтобы наполнение подставлялось без переделки вёрстки.

## Открытые пункты, требующие материалов от школы

| Код | Что нужно | Зачем | Статус |
|-----|-----------|-------|--------|
| BRAND-01 | Оригинал логотипа в SVG или PNG высокого качества | Логотип не перерисовывается; до получения файла в шапке стоит нейтральная текстовая плашка | ожидает |
| BRAND-02 | Точные фирменные цвета (синий и бордовый) из логотипа или брендбука | В токенах заданы провизорные значения `--c-navy-800` и `--c-wine-700` | ожидает |
| ANALYTICS-01 | Номер счётчика Яндекс Метрики и список действующих целей | Счётчик и цели сохраняются без изменений | ожидает |
| FORMS-01 | Куда уходят заявки из текущих форм | Получатели не меняются без проверки | ожидает |
| MEDIA-01 | Исходники фотографий в максимальном разрешении | Фото используются крупнее, требуется запас качества | ожидает |

- [ ] Проверены ширины 360, 390, 768, 1024, 1280, 1440 px
- [ ] Клавиатурный проход выполнен на всех шаблонах
- [ ] `npm run typecheck`, `npm run lint`, `npm run build` проходят без ошибок
